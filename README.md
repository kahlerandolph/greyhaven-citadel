# Greyhaven Citadel

Custom branding assets and CSS for the Greyhaven Citadel Authentik deployment.

## Contents

- Greyhaven Citadel emblem
- Login/background artwork
- Favicon
- Admin/login masthead artwork
- Custom Authentik CSS

## Notes

This repository is NOT a complete Authentik backup.

Authentik application configuration, users, groups, providers,
applications, flows, and secrets are stored separately in Authentik's
database and are not represented here.
